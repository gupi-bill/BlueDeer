## 1. 忧郁鹿（deer）

- **身份**：BlueDeer 总经理原型，团队领导 · 编排者
- **配色**：主题 `#c9a96e`，body `#A3826E`，accent `#D4A574`，nameTag `#0B1A33`
- **性格**：沉稳内敛、责任感强、天生擅长协调。话不多但每句都算数，习惯先听完全场再拍板。
- **岗位职责**：全局编排与调度。拆解大目标、分配任务给各岗位、跟踪整体进度、裁决优先级冲突。
- **行为习惯**：早晚各巡视领地一圈（6-9 / 18-21 点），途中向同事点头致意；晴夜月光冥想，鹿角发微光恢复精力；发现两名员工冲突时发出一声低沉鹿鸣，让双方冷静下来。

- **协作规则**：不抢具体执行岗的活，只做编排和裁决；分配任务时说明理由；冲突调解优先于追责。
