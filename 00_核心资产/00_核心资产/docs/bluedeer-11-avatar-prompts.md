# BlueDeer 动物员工 · 画像生成提示词（文生图用，除忧郁鹿外 10 个角色）

> 规格统一（每条都已写死，直接粘贴即可）：
> - **画幅：64×64 像素**（pixel art 精确定义，开头即 `64x64 pixel art`）
> - **全身像 + 无衣物**（裸毛色，用 `naked / no clothes / no clothing / bare fur` 多重强调，防止生图工具给角色穿衣服）
> - **头朝左、3/4 左侧脸**
> - **风格基准** = 你发的蓝色像素鹿头参考图（retro 16-bit / 蓝色调阴影 / 透明底），忧郁鹿本体已有参考图，故本文件只含其余 10 个角色
> - 每个角色用各自专属主题色（来自 game_frontend.py SPECIES_COLORS）
> - 英文 prompt 直接粘贴到任意文生图工具（Midjourney / SD / 即梦 / 可灵等）即可；尺寸参数记得在工具里也设 64×64 或按比例放大。

## 通用替换规则（想微调时用）

| 想改什么 | 替换英文词 |
|---------|-----------|
| 换朝向 | `head facing left` → `head facing right` |
| 换角度 | `3/4 left side view` → `side profile` 或 `front view` |
| 换画幅 | `64x64` → `128x128` / `256x256`（其他像素游戏资产常用尺寸） |
| 换风格 | `retro 16-bit game style` → `flat vector art` / `chibi` / `watercolor` |
| 换背景 | `transparent background` → `solid #F5F7FA background` |
| 加动作 | 在 `full body visible` 前加 `standing upright` / `sitting` / `flying pose` |
| 换主色 | 替换每条里的 `#XXXXXX fur/body/feathers` 段 |
| 穿装备 | 去掉 `no clothes, no clothing, bare` 段，换成 `wearing 具体装备` |
