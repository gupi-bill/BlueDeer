# Odysseus 使用精华指南

> 本地版 AI 工作台（聊天 + Agent + 调研 + 文档 + 笔记/日历 + 模型下载），数据全在你本机。
> 地址：**http://127.0.0.1:7000**（本机已起，不用登录）

## 0. 先记住三件事
- 模型接的是你**本地 Ollama**（默认 `deepseek-coder-v2-lite`），不花钱、不联网也能用
- 想重启服务 / 看踩坑 → 看同目录 `启动说明.md`
- 界面已经是中文；还看到英文就把那句原文发给哥补

## 1. 聊天（最常用）
- 底部输入框打字，回车发送
- 顶部下拉**选模型**（默认 deepseek-coder-v2-lite）
- 左侧栏：新建对话 / 历史记录 / 搜索对话

## 2. Agent 模式（让 AI 真干活）
- 输入框上方有 `Chat ↔ Agent` 开关，**拨到 Agent** 就进入智能体模式
- 或输入 `/` 弹命令面板，常用：
  - `/workspace 路径` —— 设工作目录（AI 能读写这目录的文件）
  - `/toggle web` —— 开/关联网搜索
  - `/toggle bash` —— 开/关命令行（让 AI 跑代码）
  - `/toggle research` —— 开/关深度调研
- 开了 bash / web 后，AI 能上网查资料、建/改文件、跑命令

## 3. 深度调研（Deep Research）
- 命令面板输入 `/research 你的主题`
- AI 自动多步联网搜、读来源、整理出一份结构化报告
- 报告在**「调研」**标签页查看

## 4. 文档 / 记忆（RAG）
- **「文档」**标签页上传文件（PDF / Word / Markdown 等）
- 之后聊天时 AI 能基于这些文档回答你
- ⚠️ 需先拉 embedding 模型才生效：`OllamaPortable\ollama.exe pull all-minilm`（国内源慢，拉完才行）

## 5. 笔记 / 任务 / 日历
- **笔记**：随手记，支持待办清单
- **任务**：可设提醒、到期日、重复规则
- **日历**：建事件、设提醒（弹窗已全中文化）

## 6. 模型食谱（Cookbook，下载模型）
- 进**「模型食谱」**标签页
- 点**扫描**，自动探测你硬件能跑哪些模型
- 搜索框找模型（如 `qwen2.5:14b`），点**下载**直接拉到本地 Ollama
- 也能贴 HuggingFace 链接下载

## 7. 对比模型（Compare）
- **「对比」**标签页：把两个模型放一起盲测，挑谁更强

## 8. 常用小贴士
- 强刷清缓存：**Ctrl + F5**
- 加本地模型：Ollama 里 `ollama pull 模型名`，Odysseus 自动发现
- 联网搜索 / 深度调研需要网络；纯聊天 / Agent 本地推理不用网
- 所有数据在你本机，不订阅、不追踪
