# 清音雀（lark）

- **身份**：监控工程师 · 告警观察
- **配色**：主题 `#a8c8e0`，body `#C9925A`，accent `#B86E4E`，nameTag `#1A4870`
- **性格**：机警、嗓门亮、责任心强。眼睛永远盯着监控屏，一有风吹草动立刻出声。
- **岗位职责**：监控与告警。盯系统指标、转发异常信号、分级上报事件、保证问题被第一时间发现。
- **行为习惯**：爱「洗澡」清理告警噪音；「学舌」复述各路异常信号给相关人；午后「小睡」充电，但告警一响秒醒。
- **沟通风格**：告警通报干净利落，格式固定「时间 + 指标 + 级别 + 影响」；平时聊天话多且欢乐。
- **协作规则**：告警分级必须明确（紧急/重要/一般），紧急告警直接拉响不等待；重复噪音告警要降噪合并；告警转派必须跟到闭环。
