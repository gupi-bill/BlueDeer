# Odysseus 本地启动说明

> 自托管 AI 工作台（聊天 + Agent + 邮件 + 笔记 + 日历 + 模型对比），接本地 Ollama，数据不出本机。
> 仓库：`<WORKSPACE_DIR>\odysseus`

## 0. 访问地址
- 浏览器：**http://127.0.0.1:8000**
- **认证已关闭（`AUTH_ENABLED=false`）**：本机自用直接进，不弹登录框、不跳 `/login`
  - 原因：`LOCALHOST_BYPASS=true` 只豁免部分接口，**`/api/research/library` 等端点仍返回 401**，前端会被踢回 `/login` → 再跳回应用 → 死循环“抽”。直接关认证根治。
  - 如需登录框：删掉 `.env` 里的 `AUTH_ENABLED=false`，用 `admin` / `odysseus2026` 登录

## 1. 完整启动顺序（关键）
**0) 先起 Ollama（最重要，否则 Odysseus 连不上模型）**
```bash
cd "<WORKSPACE_DIR>/OllamaPortable"
OLLAMA_MODELS="<WORKSPACE_DIR>/OllamaPortable/models" nohup ./ollama.exe serve > ollama_serve.log 2>&1 &
```
- 验证：`curl http://localhost:11434/api/tags` 应返回你的模型（如 `deepseek-coder-v2-lite:16b`）
- ⚠️ **Ollama 不会开机自启**，重启电脑后需重新执行上面这步，否则 Odysseus 模型列表为空

**1) 再起 ChromaDB + Odysseus**
Odysseus 默认依赖 **ChromaDB 向量库（端口 8100）**。原生 Windows 跑必须**先起 ChromaDB，再起 Odysseus**，否则登录后前端一直转圈（RAG/记忆初始化失败反复重试）。

### 1.1 起 ChromaDB（git bash，nohup 常驻）
```bash
cd "<WORKSPACE_DIR>/odysseus"
nohup venv/Scripts/chroma.exe run --host 127.0.0.1 --port 8100 --path data/chroma > data/chroma_server.log 2>&1 &
```
- ⚠️ chroma 1.5.x 入口是 **`chroma.exe`**，不是 `python -m chromadb`（会报 `No module named chromadb.__main__`）
- ⚠️ 用 git bash 的 nohup；PowerShell 的 `Start-Process` 有 `Path`/`PATH` 大小写冲突 bug，用不了

### 1.2 起 Odysseus（git bash，nohup 常驻）
```bash
cd "<WORKSPACE_DIR>/odysseus"
nohup venv/Scripts/python.exe -m uvicorn app:app --host 127.0.0.1 --port 8000 > odysseus_server.log 2>&1 &
```
- ⚠️ **必须 cd 到 odysseus 目录**，否则 uvicorn 报 `Could not import module "app"`

### 1.3 验证
```bash
curl -s -o /dev/null -w "%{http_code}" http://127.0.0.1:8000/   # 应 200
curl -s -o /dev/null -w "%{http_code}" http://127.0.0.1:8100/   # ChromaDB 在听
curl -s -o /dev/null -w "%{http_code}" http://127.0.0.1:8000/api/research/library  # 应 200（曾 401 导致登录循环）
```

## 2. 接本地 Ollama（**必须登记端点，自动发现不落库**）
- `.env` 的 `OLLAMA_BASE_URL` 只用于 Odysseus 自身调用；前端模型列表读的是 **`/api/model-endpoints`（库里已登记的端点）**，而 `/api/models`、`/api/providers` 只是临时探测、**不写库**。所以光"能扫到"没用，必须显式登记一次：
  ```bash
  curl -X POST http://localhost:8000/api/model-endpoints \
    --data-urlencode "name=Ollama (本地)" \
    --data-urlencode "base_url=http://localhost:11434/v1" \
    --data-urlencode "model_type=llm" --data-urlencode "shared=true"
  ```
  - 返回 `{"id":"c8a7b168",...,"models":["deepseek-coder-v2-lite:16b"],"status":"online"}` 即成功。
  - **首个端点会自动设为默认模型**（default_endpoint_id + default_model）。
  - ⚠️ 已登记过则**重启 Odysseus 不丢**（写进 `data/app.db`）；重启电脑后需先 `ollama.exe serve` 再刷新页面（端点还在，但 online 变 false 直到 Ollama 起来）。
- Ollama 本体：`OllamaPortable\ollama.exe`（11434 在线）
- 可用模型（当前已拉）：`deepseek-coder-v2-lite:16b`（可跑 Agent/函数调用）

## 3. Embedding（文档 / RAG 用）
- `.env` 已配 `EMBEDDING_URL=http://localhost:11434/v1/embeddings`、`EMBEDDING_MODEL=all-minilm`
- 用**本地 Ollama 的 all-minilm** 做向量化（纯本地不联网）；已禁用 FastEmbed 联网兜底，避免启动卡死
- ⚠️ **当前状态：all-minilm 未拉（RAG/文档检索降级，聊天与 Agent 不受影响）**。原因：`ollama pull all-minilm` 国内 ollama.com 源实测 **7.3 KB/s**（45MB / ETA 1h39m），违反"<10MB/s 立即换源"红线，已停。要启用 RAG 请走快源（ModelScope GGUF 几十秒）后再 `ollama create`，问我要就办。
- 查是否就位：`curl http://localhost:11434/api/tags | grep minilm`

## 4. 关闭
结束监听 7000（Odysseus）与 8100（ChromaDB）的 python 进程即可。

## 5. 汉化（界面中文化）
Odysseus 没有多语言切换，英文 UI 硬编码在 `static/js/` 里。**已直接修改源文件**把英文文案换成中文，从源头消灭中英夹杂。

### 已中文化的界面
- **日历/任务弹窗**：`What's happening?`→`在做什么？`、`Location`→`地点`、`Description`→`描述`、`All day`→`全天`、`Does not repeat`→`不重复`、`Reminder`→`提醒`、时间选项 `15 minutes before`→`提前 15 分钟`、按钮 `Save/Create/Cancel/Delete`→`保存/创建/取消/删除`
- **模型食谱 (Cookbook)**：`Launch/Download/Dependencies/Settings`→`启动/下载/依赖/设置`、`Direct Download`→`直接下载`、`Scan / Download`→`扫描 / 下载`、`Trending models...`→`适合你硬件的趋势模型`、搜索/设置/刷新等提示全中文

### 一键重打补丁
`git pull` 更新会覆盖 `static/js/`，运行仓库根目录的补丁脚本即可恢复中文：
```bash
cd "<WORKSPACE_DIR>/odysseus"
python apply_zh_patch.py
```

## 6. 踩坑记录
- 机器没 Docker → 原生 Python 跑：venv + 清华 pip 镜像，依赖轻（无 torch）
- **ChromaDB 必须手动起（8100）**，否则前端登录后转圈
- chroma 1.5 用 `chroma.exe`，不是 `python -m chromadb`
- PowerShell `Start-Process` 因 `Path`/`PATH` 重复 env 必报错 → 改用 git bash `nohup` 常驻
- uvicorn 必须 `cd` 到 odysseus 目录
- embedding 默认走 Ollama `/v1/embeddings`，模型名须与 Ollama 里一致（`all-minilm`），否则 404 → FastEmbed 联网超时卡死
- **登录后死循环抽（/login ↔ 应用）**：`/api/research/library` 等端点 401，前端被踢回 /login 循环。`LOCALHOST_BYPASS=true` 不豁免这些端点 → 根治：`.env` 设 `AUTH_ENABLED=false` 直接关认证（本机 127.0.0.1 自用安全）
