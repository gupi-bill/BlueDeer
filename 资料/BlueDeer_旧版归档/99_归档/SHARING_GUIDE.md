# BlueDeer 分享功能使用指南

零基础读者可以这样理解：你在 BlueDeer 森林公司养了一群动物员工，现在想把这片数字森林分享给朋友看，或者把某只员工的资料卡片发到朋友圈——本文档教你三种分享方式。

---

## 一、三种分享方式总览

| 方式 | 用途 | 链接有效期 | 是否需要朋友打开浏览器 |
|------|------|-----------|----------------------|
| 智能体卡片 | 单只员工精美 PNG/SVG 卡片 | 永久（图片文件） | 否 |
| 参观模式 | 朋友进入只读版管控台参观 | 24 小时（可撤销） | 是 |
| 公司快照 | 一份 Markdown 文档记录公司全貌 | 永久（文档文件） | 否 |
| 分享文案 | 一段温暖有趣的文字发朋友圈 | — | — |

**入口**：管控台右上角工具栏点击 🎁 **分享** 按钮，或按快捷键 **S**。

---

## 二、智能体卡片

### 2.1 是什么

每个智能体可生成一张 480×640 像素风格的 SVG 卡片（浏览器可直接预览/下载为 PNG）。

卡片包含：
- 像素风头像（128×128 方块）
- 名字（中文 + 拼音）
- 物种、岗位
- 年龄、健康值
- 入职日期
- 一句话自我介绍
- 技能列表（带等级）
- 角色徽章（如有非正式角色）
- 突变标记（✨ × N，如有突变）
- 最骄傲的成就
- BlueDeer 森林公司 logo

### 2.2 怎么用

**方法 A：从分享面板**

1. 按 **S** 打开分享面板
2. 切到"智能体卡片"tab
3. 从下拉框选一只员工
4. 点击"生成卡片"
5. 预览区显示卡片
6. 点击"下载 PNG"或"复制到剪贴板"

**方法 B：从员工浮窗**

1. 点击任意员工
2. 浮窗右上角点"分享"
3. 选择"生成卡片"

### 2.3 后端 API

```
GET /api/export/card?name=鹿·忧郁
→ 返回 image/svg+xml 内容

POST /api/export/card
body: {"name": "鹿·忧郁"}
→ 同上
```

### 2.4 技术说明

- 零第三方依赖，使用纯 SVG 拼接
- 物种主题色取自 `SPECIES_COLORS` 表
- 拼音用预置查表（11 个物种名字已硬编码）
- 前端可用 Canvas `ctx.drawImage` 把 SVG 转 PNG 下载

## 三、参观模式（只读共享）

### 3.1 是什么

生成一个临时链接，朋友打开后进入一个**只读版**管控台，可以自由浏览但不能操作。

### 3.2 创建参观链接

1. 按 **S** 打开分享面板
2. 切到"参观链接"tab
3. 输入朋友名字（可选，便于管理）
4. 点击"生成参观链接"
5. 复制链接发给朋友

链接格式：`http://你的服务器:8080/visit?token=xxxxxxxxxxxxxxxx`

### 3.3 参观者能做什么

| 能力 | 说明 |
|------|------|
| 自由走动 | WASD 移动、滚轮缩放 |
| 查看员工状态 | 点击员工看浮窗 |
| 查看资料库 | 已故同事记忆晶块 |
| 查看公开对话 | 最近公开消息 |
| 看进化树 | 资料库的突变历史 |

### 3.4 参观者不能做什么

| 禁止操作 | 拦截方式 |
|---------|---------|
| 下达任务 | `/api/inject`、`/api/agent_command` 等 403 |
| 修改设置 | `/api/immersive_settings`、`/api/theme` 等 403 |
| 操作智能体 | `/api/interact`、`/api/recruit` 等 403 |
| 进入聊天 | `/api/chat` 403 |
| 登出监工 | `/logout` 403 |
| 访问监工主页 `/` | 403，引导到 `/visit` |

### 3.5 管理参观 token

在分享面板的"参观链接"tab，可看到所有 token 列表：

- **创建时间**
- **过期时间**（创建后 24 小时）
- **剩余有效时间**
- **访问次数**、**最后访问时间**
- **状态**（有效/已撤销/已过期）

每个 token 有两个操作：
- **撤销**：标记 `revoked=true`，token 立即失效但保留记录
- **删除**：从列表彻底移除

### 3.6 顶部横幅

参观者浏览器顶部会显示：

```
🌲 你正在参观 [监工名字] 的森林公司 · 只读模式
```

### 3.7 后端 API

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/share/tokens` | 列出所有 token |
| POST | `/api/share/tokens` | 创建新 token，body: `{"name":"朋友A"}` |
| POST | `/api/share/revoke` | 撤销 token，body: `{"token":"xxx"}` |
| POST | `/api/share/delete` | 删除 token，body: `{"token":"xxx"}` |
| GET | `/visit?token=xxx` | 参观入口 |

### 3.8 鉴权机制

`game_server.py` 的 `_require_auth()` 优先检查 `bluedeer_visit` cookie：

```python
1. 如果带 bluedeer_visit cookie
   → 校验 token 有效性
   → 检查路径是否在白名单（VISITOR_ALLOWED_PATHS）
   → 不在白名单返回 403
2. 否则走监工登录态校验
```

### 3.9 持久化

token 列表持久化到 `data/share_tokens.json`：

```json
{
  "tokens": [
    {
      "token": "CfWPhNS8Pw7e...",
      "created_ts": 1784639391.96,
      "expires_ts": 1784725791.96,
      "name": "朋友A",
      "revoked": false,
      "last_access_ts": 0,
      "access_count": 0
    }
  ]
}
```

每次访问自动更新 `last_access_ts` 和 `access_count`。

## 四、公司快照导出

### 4.1 是什么

一键导出一份 Markdown 格式的"公司状态快照"，包含：

- 导出时间
- 监工档案（森林印记余额）
- 当前存活员工列表（名字、物种、年龄、健康、情绪、岗位）
- 技能矩阵（横轴技能、纵轴员工）
- 已故员工纪念列表
- 资源状态（食物资源、森林印记）
- 本月关键事件时间线（最近 10 条）
- 今日站会摘要（如有）

### 4.2 怎么用

1. 按 **S** 打开分享面板
2. 切到"公司快照"tab
3. 点击"导出 Markdown"
4. 浏览器自动下载 `bluedeer_snapshot_YYYYMMDD_HHMM.md`

### 4.3 用途

- **存档**：每周/每月存一份，看公司演变
- **社区分享**：发到 GitHub Issue、Reddit、V2EX
- **开发日志**：作为版本发布的"公司状态报告"

### 4.4 后端 API

```
GET /api/export/snapshot
→ 返回 text/markdown 内容
```

## 五、分享文案自动生成

### 5.1 是什么

每次分享时，LLM 自动写一段温暖、有趣的文字，突出你的森林公司特色。LLM 不可用时降级用模板。

### 5.2 怎么用

1. 按 **S** 打开分享面板
2. 切到"分享文案"tab
3. 点击"生成文案"
4. 预览区显示文案
5. 点击"复制到剪贴板"

### 5.3 示例文案

```
我的数字森林公司已经运行 365 天了！🦌忧郁鹿领导着 10 位动物员工，
松鼠写了 847 段代码，渡鸦收藏了 23 个已故同事的记忆。
狐狸每天毒舌但从未真的生气过。欢迎来参观 → [链接]
```

### 5.4 后端 API

```
GET /api/export/share_text
→ {"text": "我的数字森林公司已经运行 ..."}
```

### 5.5 LLM 调用

- 优先调 `router.complete(prompt)`
- 失败时降级用模板（包含运行天数、员工数、关键物种名字）
- prompt 突出"温暖、有趣、独特性"

## 九、安全说明

| 风险 | 防护措施 |
|------|---------|
| 参观 token 被滥用 | 24 小时自动过期 + 监工可随时撤销 |
| 参观者绕过权限 | 路径白名单 + 黑名单双重过滤 |
| 参观者获取敏感数据 | 只读 API 白名单，所有写操作 403 |
| 参观者登出监工 | `/logout` 在禁止前缀中 |
| 卡片泄露个人信息 | 卡片只包含员工数据，不含监工信息 |
| 快照泄露 LLM API key | 快照不含任何密钥/配置 |

## 十一、设计取舍

| 取舍 | 原因 |
|------|------|
| 卡片用 SVG 不用 PNG | 零第三方依赖，浏览器原生支持 |
| 参观模式 token 24h 过期 | 平衡分享便利性与安全 |
| 参观者用 cookie 不用 URL token | 避免每次跳转都带 token |
| 快照用 Markdown 不用 PDF | 零依赖、文本可 diff、社区友好 |
| 文案 LLM 降级用模板 | LLM 不可用时仍有输出 |
| 不实现 GIF 合成 | 复杂度过高，留给后续 commit |
